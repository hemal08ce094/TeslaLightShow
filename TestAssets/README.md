## How to Use in the App

1. **Open the Tesla Light Show app**
2. **Create a new project**
3. **Tap "Import Audio"**
4. **Select TestAudio.wav from TestAssets folder**
5. **Tap "Generate" in Auto-Sync section**
6. **Adjust sensitivity if needed (recommended: 1.5)**
7. **Preview the generated light show**
8. **Export and test on your device**

## Troubleshooting

### If beat detection doesn't work well:
1. Increase sensitivity (try 2.0-2.5)
2. Try a different flash duration
3. Manually edit frames in timeline

### If audio doesn't play:
1. Check file permissions
2. Ensure file is not corrupted (verify ~2.6 MB size)
3. Try re-importing the file

### If waveform doesn't show:
1. Wait for audio processing to complete
2. Check that audio file loaded successfully
3. Restart the app if needed

## Technical Details

### Beat Pattern:
The audio uses a simple repeating pattern:
```
Time:   0.0s  0.5s  1.0s  1.5s  2.0s  2.5s  3.0s ...
Bass:    ●     ●     ●     ●     ●     ●     ●
Hi-hat:    ○     ○     ○     ○     ○     ○     ○
```

Where:
- ● = Strong bass beat (easy to detect)
- ○ = Hi-hat accent (more subtle)

### Why This Pattern Works:
- **Predictable timing** - Easy to verify beat detection accuracy
- **Clear transients** - Strong energy peaks for detection algorithm
- **Minimal complexity** - Reduces false positives
- **Tesla-compatible** - Meets all Tesla light show requirements
